# 模拟盘前向跟踪（paper）

## 目的

用 QMT 模拟账户按真实时间推进策略，验证**执行链路**（信号、委托、成交、持仓、NAV），
不是再跑历史回测，也不是实盘。

## paper 版和回测版的区别

- `REBALANCE_DATES=[]`：不再用历史日期表，改为每月第一个交易日触发；
- 信号用前一日，成交用当日；
- NAV 追加写，不因重启清空；
- `.state` 记录上次调仓月，避免重启后同月重复调仓；
- 股票池用刷新后的 `UNIVERSE_CHANGES`（13 个版本），未来成分变更需人工更新；
- 仍然是 QMT 内置策略，不启动/不下单由仓库完成。

## 启动步骤

1. QMT → 新建 Python 策略；
2. 粘贴 `output/qmt/nfr_mom_lowvol_paper.py`（GBK）；
3. 确认 `PAPER = True`、`REBALANCE_DATES = []`、账户号来自 `config/qmt.json`；
4. 编译；
5. 走 **模型交易 → 新建策略交易**，选模拟账户、日线周期，启动；
6. **2026-12-01** 开始，记录起点。

不要点“回测”：回测是历史数据，不是前向。
也不要直接从 2026-11-30 启动：paper 版按“每月第一个交易日”触发，11-30 属于 11 月，
会在 11-30 和 12-01 连续触发两次月度调仓。

如果必须 11-30 启动，先在 `STATE_PATH` 写入 `2026-11`，让它跳过 11 月、到 12-01 再调仓。

## 每日记录

收盘后记录：

```
output/paper/20261130/
  nav.csv
  orders.csv
  trades.csv
  positions.csv
  incidents.md
```

至少包含：

- 当日 `picked=` 日志；
- 委托/成交：代码、方向、数量、价格、状态；
- 持仓/现金/NAV；
- 异常：资金不足、零股、涨跌停、停牌、跳过单。

## 每次调仓对账

| 项 | 引擎影子 | QMT paper |
|---|---|---|
| 选中标的 | top8 | 日志 picked |
| 权重 | inverse_vol | 实际成交权重 |
| 卖出 | 清掉未入选 | 实际卖出 |
| 买入 | 目标股数 | 实际成交/跳过 |
| 现金 | 约 0 | 剩余现金 |
| 成本 | 10bp | 实际佣金 |

注意：paper 版是**每月第一个交易日**调仓，影子引擎是**月末**调仓，存在一天时滞；
比较时以“下一交易日实际持仓”对齐，不要求 NAV 逐日完全一致。

## 验收标准

60 个交易日 / 3 次调仓后：

- top8 与影子一致（允许一天时滞）；
- 无代码/参数导致的跳单；
- 跟踪误差 < 6%；
- 累计净值差 < 约 3%；
- 所有异常有记录。

不满足先修执行/数据，不改策略。

## 不做

- 不接实盘；
- 不在窗口内调参；
- 不用 20 天短期收益判断策略；
- 不把 QMT 000300 基准当等权基准。
