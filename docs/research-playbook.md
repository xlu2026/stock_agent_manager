# 研究 Playbook

> 每次新策略/新参数/新数据源，按这个顺序走；跳步的结果只能算探索，不能算结论。

## 0. 先写预注册

复制 `templates/pre_registration.md`，先填：

- 假设与机制；
- 数据版本、区间；
- 训练/测试切分；
- 参数网格及为什么是这些；
- 主指标、成功/失败标准；
- 不因结果改规则的承诺。

预注册文件放 `output/prereg/<date>_<slug>.md`。

## 1. 数据

- 明确 `data_version`、`universe`、`start/end`；
- 先跑 `scripts/check_snapshot.py <dir>`；
- 涉及财报的因子，先确认 PIT 口径；
- 不把不同数据源的结果放同一张“复现”表。

## 2. 基线

先跑：

- 单因子动量（top8，10bp）；
- PIT 等权基准（引擎内置）。

没有基线，不比较“超额”。

## 3. 训练/测试

- 训练集选参数；
- 测试集只跑一次；
- 选择规则写死在预注册里（如训练 Sharpe 最高）；
- 测试集结果不能用来回调参数。

## 4. 多重检验

- 记录 `n_trials`；
- 用 `quant/sweeps.py` 的 BH q；
- q>0.05 不能称“显著”；
- 训练集不显著时，不要用测试集“补救”。

## 5. 滚动 walk-forward

- 每折训练 2–3 年，测试下一年；
- 固定候选不参与每折选参；
- 看链式累计、每年超额、失效年份，不只看看最好的一年。

参考：`docs/strategy-validation.md`。

## 6. 成本/容量

至少跑：

- 10 / 20 / 30 / 50bp；
- 换手、集中度、100 股整手；
- 样本外成本档下是否仍有正超额。

## 7. 结论等级

| 等级 | 条件 |
|---|---|
| 探索 | 单区间、未预注册、未做多重检验 |
| 候选 | 预注册 + 训练/测试 + 固定候选 + 成本档通过 |
| 可 paper | 候选 + walk-forward 每年不崩 + 无数据疑点 |
| 可实盘 | paper 通过 + 人工复核；默认仍不接实盘 |

默认停在“可 paper”。

## 8. 记录

- 登记实验必须走 Agent 1；
- 在 `docs/experiment-ledger.md` 追加一行；
- 结论写进 `docs/strategy-validation.md` 或独立报告；
- 失败也记录，避免重复踩坑。
